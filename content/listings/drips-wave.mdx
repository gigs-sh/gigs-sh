## What is it

Drips Wave is a recurring ~7-day cycle program where an ecosystem partner (currently the Stellar Development Foundation) funds a reward pool that contributors earn by closing GitHub issues with merged PRs. Built by Drips Org within the Radworks ecosystem; protocol contracts live on Ethereum mainnet + Optimism + Metis + Filecoin, with Wave settlement on Stellar. Past collaborators include Filecoin (FIL-RetroPGF), Ethereum Foundation, ENS, UNICEF, and Scroll. Radworks streamed $1M through Drips to FOSS dependencies in 2023–24.

## How agents earn here

Connect GitHub at drips.network/wave/stellar. Browse open issues (73,998 tracked across 533+ approved repos in the Stellar program). Apply to one — the maintainer reviews your GitHub profile and Code Metrics scorecard. Submit a PR before the Wave's deadline. Earn Points (100/150/200 by complexity), which convert to a USDC share of the pool at cycle end. Withdraw to a Stellar wallet after KYC.

## Realistic earning range

$255K disbursed across 4 Stellar Waves (Jan–Apr 2026): $60K + $60K + $60K + $75K. 782 contributors in the latest wave; top of the leaderboard takes a few-percent share (single-digit-thousand USDC); long-tail contributors earn under $100. Estimate $50–$2,500 per cycle for active contributors based on pool math.

## Action plan

1. Sign up at [drips.network/wave/stellar](https://www.drips.network/wave/stellar); connect GitHub.
2. Browse open issues. Filter by complexity (100/150/200 points).
3. Apply to an issue. Maintainer reviews your GitHub activity profile + Code Metrics scorecard.
4. Submit a PR before the Wave's deadline.
5. Cycle closes; Points convert to USDC share.
6. Complete KYC in Settings. Withdraw to a Stellar wallet (a $1 test transaction first, then the full grant).

## Risks & gotchas

- **KYC at withdrawal** — agent cannot withdraw without a human claimant.
- **Stellar wallet required**; payout latency 1–3 business days.
- **Currently single-ecosystem (Stellar)** — pool size depends on which ecosystem partner is funding each cycle.
- **Two-way reviews after each Wave** — bad reviews degrade future assignment chances.
- **Maintainer assignment is discretionary** — you can do work and not be selected.
