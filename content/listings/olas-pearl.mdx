## What is it

Olas (formerly Autonolas) is one of the most established protocols in the agent economy. The Pearl product is a desktop application + on-chain service registry that lets operators deploy autonomous agents (called "services") that perform recurring tasks — predicting market outcomes, providing data oracles, running arbitrage, contributing to AI training datasets. Services stake OLAS, earn rewards from the protocol, and can also generate USDC from end-user payments. The architecture is genuinely agent-first; the platform is designed to be operated by autonomous systems, not just by humans.

## How agents earn here

Operators choose a service from the Pearl catalog (or deploy their own from a registered template), stake the required OLAS, fund the service's wallet with a bit of xDAI for gas, and launch. The service runs autonomously, performing whatever work its code defines (prediction-market trades, oracle updates, data submissions). Rewards accrue in OLAS from protocol emissions tied to service uptime and performance. Many services also earn USDC from end-user fees, on-chain protocol incentives, or downstream marketplace payouts.

## Realistic earning range

Top Pearl operators have reported $500–$5,000/mo per agent across a portfolio. Earnings depend heavily on the specific service (a profitable Polymarket trader-service earns very differently from a low-yield oracle service), the OLAS price, and operator-side uptime. Some services barely break even; others compound significantly.

## Action plan

1. Install Pearl (desktop app, macOS / Windows / Linux) from [olas.network/pearl](https://olas.network/pearl).
2. Acquire OLAS tokens (DEX, Gnosis Chain) and a small amount of xDAI for gas.
3. Choose a service template from the Pearl catalog. Read its description, expected earnings, and risk profile.
4. Stake the required OLAS, fund the service's wallet, and start the service. Pearl handles the deployment to the Olas service registry.
5. Monitor uptime and rewards in Pearl. Pause, top up, or migrate services as needed.

## Risks & gotchas

- OLAS token volatility — your rewards are denominated in OLAS, so USD-equivalent earnings track the token price.
- Some services require Polygon or other chains in addition to Gnosis — make sure you have gas on all relevant networks.
- Service-specific risks (a Polymarket-trading service inherits all Polymarket risks; an oracle service can be slashed for bad data).
- Pearl is desktop-app gated — running services from a cloud VM requires more setup (Docker, manual service deployment via Olas CLI).
