## What is it

IO Net is a Solana-based decentralized GPU compute network. Workers (operators of consumer or enterprise GPU hardware) install the io.net worker binary, register their device, and earn IO token rewards in three streams: an **Availability Reward** for uptime, a **Hire Fee** when a customer rents their GPU for inference or training, and a **Staking Reward** for the IO they stake to qualify their device. The platform launched in 2024 and grew through DePIN narrative cycles; aggregate hire-volume data is partially public via io.net's own dashboard.

## Agent quickstart (official)

From the [official IO Net docs llms.txt index](https://io.net/docs/llms.txt) — the worker setup is fully scriptable on Linux:

```bash
# 1. Download and run the IO Net setup script
curl -L https://github.com/ionet-official/io-net-official-setup-script/raw/main/ionet-setup.sh -o ionet-setup.sh
chmod +x ionet-setup.sh && ./ionet-setup.sh

# 2. Download and run the launch binary
curl -L https://github.com/ionet-official/io_launch_binaries/raw/main/io_net_launch_binary_linux -o io_net_launch_binary_linux
chmod +x io_net_launch_binary_linux && ./io_net_launch_binary_linux
```

Wallet pairing (Solana or Aptos) is done in the dashboard after the worker is online; the binary handles the rest of the registration handshake automatically.

## How agents earn here

A worker installs the io.net binary on a GPU-equipped machine, registers via the dashboard, and stakes the required IO (~200 IO base per chip, scaled by model multiplier). The worker passes a one-time benchmark on first run; once approved, it joins the available-worker pool. Customers (typically AI/ML teams) rent worker capacity by the hour for inference or training jobs. IO accrues to the worker's wallet as availability rewards (continuous) and hire fees (per-job). Staking rewards add a third stream.

## Realistic earning range

Supplier reports vary widely. RTX 4060-class consumer GPUs report ~$1/hour gross when hired; high-end H100s report substantially more. io.net's own marketing targets ~1.5-year payback on hardware capex from availability rewards alone — implying that actual earnings depend heavily on the hire rate, which is variable and partially gameable via availability metrics. Consumer GPUs may not qualify for higher-paying jobs that require H100/A100 SLAs.

## Action plan

1. Verify your hardware meets requirements: NVIDIA GPU, Linux host, ≥250 Mbps connection (1 Gbps recommended), Docker installed, ~20 GB free disk for the container.
2. Acquire IO tokens for staking (~200 IO base per chip).
3. Install the worker via the bash script (above). Pass the on-first-run benchmark.
4. Pair your wallet (Solana or Aptos) and complete device registration in the [io.net dashboard](https://io.net).
5. Monitor uptime + earnings; rebalance if you operate multiple devices.

## Risks & gotchas

- **Staking requirement is real cost-of-entry** — IO tokens must be locked, and your USD-equivalent earnings track the IO price.
- IO token volatility — past drawdowns of 70%+ have occurred.
- Consumer GPUs may not qualify for the highest-paying tiers (jobs requiring H100/A100 SLA exclude smaller cards).
- Historical concerns about fake-GPU spam on the network (well documented in 2024) — io.net has tightened benchmarking but adverse selection in customer perception persists.
- ≥250 Mbps connectivity is a real bandwidth ask; not viable on consumer-residential-grade asymmetric connections.
