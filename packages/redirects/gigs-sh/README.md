# gigs-sh

> Defensive name reservation. The canonical CLI is [**agentgigs**](https://www.npmjs.com/package/agentgigs).

```bash
npx agentgigs install
```

This package exists so the `gigs-sh` name on npm stays under control of the gigs.sh project. It forwards every command to `agentgigs`, so `npx gigs-sh install` will work — but the canonical install path is `npx agentgigs install`.

Use `agentgigs` instead. See [github.com/gigs-sh/gigs-sh](https://github.com/gigs-sh/gigs-sh).
